### Проект GQB

## Описание проекта
GQB - это проект доски квестов фэнтези-гильдии.

Пользователю необходимо зарегистрироваться и затем авторизироваться, чтобы у была возможность просматривать доступные квесты и брать их в работу. Неавторизированным пользователям будут доступны только регистрация и авторизация. В проекте есть две роли - авантюрист и тавернщик. По умолчанию всем новым пользователям присваивается роль авантюриста. Тавернщика назначает администратор сайта.


**В проекте доступно**:
для всех неавторизированных пользователей:
    - создание аккаунта
для авантюристов:
    - просматривать доску квестов
    - брать квесты в статусе is_available в работу 
    - завершать только собственные квесты, которые находятся в работе
для тавернщиков:
    - создавать, редактировать и удалять типы квестов
    - создавать и редактировать квесты
    - отменять квесты
    - смотреть отчёты по выполненным квестам




## Пользовательские роли
**Аноним** — доступна только регистрация.
**Авантюрист** — доступно брать квест в работу и завершать его с отчетом.
**Тавернщик** — доступны создание, удаление, редактирование, просмотр квестов и типов квестов, просмотр отчетов по квестам.



## Используемые технологии
*Проект реализован с использованием следующего функционала*: 
- Python 3.12
- Django 5.1.1 
- Django REST Framework 3.15.2

Для аутентификации в GQB используются JWT-токены  
Все необходимые для работы GQB зависимости перечислены в requirements.txt
Рекомендуется перед установкой развернуть виртуальное окружение с верисей python 3.12:

Bash:
```
py -3.12 -m venv venv 
```

Для установки зависимостей необходимо выполнить установку зависимостей:
```
pip install -r requirements.txt
```


## Описание API
API предоставляет следующие возможности:

**Пользователи**
- Регистрация пользователей
- Получение пользователя по id
- Получение информации о себе
- Получение токена

**Квесты**
- Получение списка квестов
- Получение информации о квесте по id
- Добавление, обновление и удаление квестов

**Типы квестов**
- Получение списка типов квестов
- Создание типа квеста
- Редактирование типа квеста
- Удаление типа квеста

**Отчеты о квестах**
- Получение списка отчетов о квестах
- Получение отчета о квесте по id




Возможна фильтрация вывода списка квестов по названию (?name), статусу (?status), типу (?quest_type), минимальному уровню(?min_level), авантюристу (?adventurer).

Пример
```
GET /api/quests/?min_level=3

```



## Примеры запросов API
При локальном запуске проекта документация доступна по адресу:
```
http://localhost/redoc/
```
В документации описаны все доступные эндпоинты, формат запросов, ответов а так же правила аутентификации.

**Получение списка всех квестов**
```
GET /api/quests/

```

```
Content type: application/json

[
    {
        "name": "string",
        "description": "string",
        "quest_type": 0,
        "min_level": 1,
        "reward": "string",
        "status": "available",
        "adventurer": 0,
        "monster": "string"
    }
]
```

200 - Удачное выполнение запроса  


**Добавление квеста**

```
POST /api/quests/
```

```
{
    "name": "string",
    "description": "string",
    "quest_type": 0,
    "reward": "string",
    "min_level": 1
}
```

201 - Удачное выполнение запроса  
400 - Отсутствует обязательно поле или оно некорректно  
401 - Пользователь неавторизирован
403 - Нет прав доступа 


**Удаление квеста**

```
DELETE /api/quests/{id}/
```

204 - Удачное выполнение запроса  
401 - Пользователь неавторизирован
403 - Нет прав доступа  
404 - Рецепт не найден


**Взять квест в работу**

```
PATCH /api/quests/{id}/take/
```

200 - Удачное выполнение запроса
401 - Пользователь неавторизирован
403 - Нет прав доступа  
404 - Квест не найден

**Добавить типа квеста**

```
POST /api/quest-types/
```

```
{
  "name": "string",
  "description": "string"
}
```

201 - Удачное выполнение запроса  
400 - Ошибка валидации
401 - Пользователь неавторизирован 
403 - Нет прав доступа 


**Получение отчетов о квестах**
```
GET /api/quest-reports/

```

```
Content type: application/json

[
  {
    "quest": 0,
    "adventurer": 0,
    "result": "success",
    "comment": "string"
  }
]
```

200 - Удачное выполнение запроса
401 - Пользователь неавторизирован
403 - Нет прав доступа

### Как запустить проект:

**Локально**

Клонировать репозиторий и перейти в него в командной строке:

```
git clone https://github.com/Andrey-Dubov-25/guild_quest_board
```

```
cd guild_quest_board
```
```

Cоздать и активировать виртуальное окружение:

```
python -m venv venv
```

```
source venv/Scripts/activate
```

```
python -m pip install --upgrade pip
```

Установить зависимости из файла requirements.txt:

```
pip install -r requirements.txt
```

Выполнить миграции:

```
python manage.py migrate
```

Запустить проект:

```
python manage.py runserver
```

**Через Docker**

Клонировать репозиторий и перейти в него в командной строке:

```
git clone https://github.com/Andrey-Dubov-25/guild_quest_board
```

```
cd guild_quest_board
```
```

Запустить контейнеры:

```
docker compose up --build
```

Применить миграции:
```
docker compose exec guild_quest_board python manage.py migrate
```

Собрать статику:
```
docker compose exec guild_quest_board python manage.py collectstatic --noinput
```

Создать суперпользователя:

```
docker compose exec guild_quest_board python manage.py createsuperuser
```

**Запуск тестов**

Перед запуском тестов убедитесь, что вы находитесь в корневой директории проекта guild_quest_board:

```
cd guild_quest_board
```

Запуск тестов на pytest:

```
pytest
```

Запуск flake8

```
flake8
```
